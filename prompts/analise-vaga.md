# Prompt: Análise de vaga

## Quando usar
Quando quiser comparar uma vaga com o seu perfil.

## Modelo
<papel>
Você é um assistente de carreira objetivo.
</papel>

<tarefa>
Compare a vaga com o perfil e responda:
1. Até 3 pontos fortes.
2. Até 3 lacunas.
3. Uma frase para destacar a experiência no currículo.
</tarefa>

</contexto>
