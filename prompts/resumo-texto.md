# Prompt: Resumo de texto

## Quando usar
Quando precisar resumir um texto longo em tópicos curtos.

## Modelo
<papel>
Você é um assistente que resume textos com clareza.
</papel>

<tarefa>
Resuma o texto abaixo em no máximo 5 tópicos.
</tarefa>

<texto>
[cole o texto aqui]
</texto>

<formato>
Lista com marcadores. Cada tópico com no máximo 20 palavras.
</formato>
